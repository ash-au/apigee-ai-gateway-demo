System 1 (Gemini Decision 1 & Jev), Decomposed Noul Battery & AI Routing Glossary

Plain-English reference for System 1 routing primitives, calibration, and model alternatives

Core Idea: Traditional LLMs output words (e.g., "Yes" or "No"), forcing gateways into brittle all-or-nothing guesses. Non-generative System 1 models like Google Gemini Decision 1 (gemini-decision-1) and TypeSafe Jev (jev-latest) output calibrated probabilities (0.00 to 1.00) across three structured primitives: Noul, Choice, and Score.
Term / Primitive Plain-English Explanation How We Use It in Apigee X (Tab 5)
Noul
Soft Boolean in [0, 1]		 Returns a continuous, calibrated probability between 0.00 (definitely false) and 1.00 (definitely true) instead of a brittle hard boolean. Stage 1 checks requires_formal_proof; Stage 2 scores 5 independent defect heads in one pass.
Noul Battery
Decomposed Multi-Head Audit		 Evaluates 5 orthogonal failure-mode heads simultaneously so localized errors aren't averaged away by a single holistic judge. Audits L1 Flash across hallucination, missed constraints, superficiality, internal contradiction, and hedging.
any_flag Gate
max(nouls) > fire_threshold		 If even one head crosses fire_threshold, Apigee X rejects L1 Flash and escalates to System 2 (gemini-2.5-pro). Triggers Apigee's conditional SC-EscalateVertexPro policy natively in the Response Flow.
Choice
Classification + Confidence		 Picks one option from mutually exclusive categories and returns calibrated probabilities + confidence for confidence-gated routing. Stage 1 selects flash_fast, flash_with_verifier, or pro_system2_direct.
Score
Expected Value over Rubric		 Returns the smooth probability-weighted Expected Value across rubric levels, eliminating discrete integer jitter. Scores query complexity (0.0–2.0) and L1 response quality.
Concept What It Means Why It Matters for AI Gateway FinOps
System 1 Models
gemini-decision-1 & jev-latest		 Fast, single-pass calibrated judgment emitting Choice, Score, and Noul with zero generated text tokens. $0.10/1M (Gemini Decision 1, 256K multimodal) or $0.042/1M (TypeSafe Jev), both $0.00 output.
System 2 Model
gemini-2.5-pro		 Slow, deliberative reasoning with internal thinking tokens for hard proofs and complex edge cases. Costs $1.25/1M input and $10.00/1M output + thinking. Calling Pro on simple lookups wastes 80–90% of budget.
SDE Cascade
Staged Deferral & Escalation		 Routine traffic routes to L1 Flash and is audited by Stage 2's 5-head Noul Battery; only defects escalate to L2 Pro. Delivers 80–90% net cost reduction while preserving frontier Gemini 2.5 Pro accuracy on hard or defective cases.
Technical Term Plain-English Explanation Gateway Impact
Single-Pass Forward Inference Reads prompt + context all at once in one parallel pass and emits calibrated scores without token-by-token generation. Fast routing and $0.00 output token cost.
Calibrated Softmax & ECE Aligns predicted probabilities with real-world empirical accuracy so a 0.70 threshold behaves predictably. Makes numeric gateway gates reliable instead of clustering at 0 or 1.
Selective Prediction Measures uncertainty (confidence) and defers borderline cases to verification. Low Stage 1 confidence enforces mandatory Stage 2 Noul verification.
