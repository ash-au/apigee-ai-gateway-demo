3. Engineering Honesty & Architectural Trade-offs

  • Thinking Tokens Explicitly Billed: Gemini 2.5 models generate internal reasoning tokens (thoughtsTokenCount) billed at the output rate. Both sides of this demo surface and bill thinking tokens explicitly.
  • Gateway Overhead Included: Every embedding lookup (text-embedding-005) and multi-turn pruning summary (gemini-2.5-flash) is added to the gateway's billed token count and USD cost.
  • Honest Cascade Double-Billing: When L1 (Flash) fails the reliability threshold (g < 0.80) and escalates to L2 (Pro), the gateway bills both the L1 attempt and the L2 completion.
  • CPU Compression Latency vs. Token Savings: Running LLMLingua-2 BERT token classification on Cloud Run CPU adds ~1.5–6s of compute latency on long RAG contexts; in high-throughput production, deploying the compressor on an L4 GPU sidecar drops compression latency below 60ms.
