Vertex AI Pricing Basis (Standard)

Gemini 2.5 Pro: $1.25 / 1M input, $10.00 / 1M output (incl. thinking). Gemini 2.5 Flash: $0.30 / 1M input, $2.50 / 1M output. Gemini Decision 1: $0.10 / 1M input ($0 output). TypeSafe Jev: $0.042 / 1M input ($0 output).

Pure Apigee X Policy Enforcement

Quotas, Model Armor, Semantic Cache, and System 1 / System 2 Pre-Routing + Post-Verification run directly inside Apigee X using native policies, encrypted KVM, TargetServers, and ServiceCallouts.

System 1 / System 2 & Noul Glossary

System 1 (Fast Classifier)

Ultra-cheap classification pass (Gemini Decision 1 or TypeSafe Jev) that scores query complexity in milliseconds before an expensive reasoning LLM is called.

System 2 (Deep Reasoner)

High-capability model (Gemini 2.5 Pro) reserved only for complex queries or escalated defects.

Noul Quality Gate

Post-generation verification battery scoring L1 Flash responses for grounding, hallucination, completeness, and safety — automatically escalating to Gemini 2.5 Pro if any detector fires.
