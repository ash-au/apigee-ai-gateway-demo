System 1 (TypeSafe Jev), Decomposed Noul Battery & AI Routing Glossary

Plain-English reference for System 1 routing primitives, calibration, and model alternatives

Core Idea: Traditional LLMs output words (e.g., "Yes" or "No"), forcing gateways into brittle all-or-nothing guesses. TypeSafe Jev is a non-generative System 1 model that outputs calibrated probabilities (0.00 to 1.00) across three structured primitives: Noul, Choice, and Score.
Term / Primitive Plain-English Explanation How We Use It in Apigee X (Tab 5)
Noul
Soft Boolean in [0, 1] 		Instead of returning a hard true or false, a Noul returns a continuous, calibrated probability between 0.00 (definitely false) and 1.00 (definitely true). Pass optional criteria: {"true": "...", "false": "..."} to anchor positive vs. negative conditions. In Stage 1, requires_formal_proof returns 0.99 on the Raft/FLP theorem query and 0.01 on the KMS key rotation lookup. In Stage 2, each defect check returns a calibrated probability (e.g., missed_user_constraint: 0.99).
Noul Battery
Decomposed Multi-Head Audit 		Why single questions fail: Asking one holistic question ("Is this response bad enough to escalate?") averages out localized errors, returning a deceptively low score (~0.04–0.15) even when one number was hallucinated. A Noul Battery evaluates 5 orthogonal failure-mode heads simultaneously in one pass. Our Stage 2 verifier runs 5 Noul heads:
1. hallucinated_or_contradicts_context
2. missed_user_constraint
3. superficial_or_unproven
4. internal_contradiction
5. hedging_or_refusal
Plus __overall__::holistic_escalate_judge for comparison.
any_flag Gate
max(nouls) > fire_threshold 		Instead of averaging the 5 defect heads, we take the maximum: any_flag = max(head_1, ..., head_5) > 0.70. If even one head crosses fire_threshold (marked <== FIRES), Apigee X rejects L1 Flash and escalates to System 2 (gemini-2.5-pro). In Scenario 3, when L1 Flash fabricates a region and skips a bullet, missed_user_constraint hits 0.99 <== FIRES and hallucinated_or_contradicts_context hits 0.89 <== FIRES, immediately triggering L2 Pro recovery.
Choice
Classification + Confidence 		Picks one option from mutually exclusive categories and returns the winning choice, calibrated probabilities summing to 1.00, and overall confidence (0.00 to 1.00) for confidence-gated routing. In Stage 1, target_tier classifies into flash_fast, flash_with_verifier, or pro_system2_direct, gated by confidence ≥ 0.75.
Score
Expected Value over Rubric 		Computes the probability of each rubric level (P(0), P(1), P(2)) and returns the smooth Expected Value: E[Score] = 0·P(0) + 1·P(1) + 2·P(2) in [0.0, 2.0], eliminating discrete integer jitter. Stage 1 scores query complexity (0.00 to 2.00) to tune Gemini's thinkingBudget; Stage 2 scores response_quality of the L1 Flash output.
Concept What It Means Why It Matters for AI Gateway FinOps
System 1 Model
jev-latest		 Inspired by Kahneman's Thinking, Fast and Slow: fast, instinctive, single-pass judgment. Reads the state once and outputs calibrated probabilities (Choice, Score, Noul) in ~190–220ms. Costs $0.042 per 1M input tokens and $0.00 for output tokens (~30x cheaper on input than Gemini 2.5 Pro). Ideal for API gateway routing and verification gates.
System 2 Model
gemini-2.5-pro		 Slow, deliberative, step-by-step reasoning that generates internal thinking tokens (thoughtsTokenCount) and autoregressive text completions to solve hard proofs or complex edge cases. Costs $1.25 / 1M input and $10.00 / 1M output + thinking tokens. Calling System 2 on every simple lookup wastes 80–90% of enterprise AI budgets.
Direct System 2 Fast-Track
pro_system2_direct		 Standard cascades send every query to L1 Flash first, wasting latency and tokens on formal proofs Flash cannot solve. When Stage 1 Jev detects choice == "pro_system2_direct" (confidence ≥ 0.75) or requires_formal_proof ≥ 0.70, Apigee X's Route-VertexPro routes straight to Gemini 2.5 Pro.
SDE Cascade
Staged Deferral & Escalation		 Routine traffic (~85%) routes to L1 (gemini-2.5-flash) and is audited by Stage 2's 5-head Noul Battery. Only if a defect head fires (> 0.70) does Apigee escalate to L2 Pro. Delivers 85%–89% net cost reduction on routine traffic while preserving frontier Gemini 2.5 Pro accuracy whenever L1 Flash hallucinates or misses a constraint.
Technical Term Plain-English Explanation Gateway Impact
Autoregressive Text Generation Generative LLMs write answers one token at a time in a sequential loop, re-running the neural network for every single output word. High latency (1–6 seconds) and high output/thinking token costs.
Single-Pass Forward Inference System 1 models (Jev, DeBERTa) read the prompt + context all at once in one parallel pass and immediately emit classification/probability scores. ~190ms latency and $0.00 output token cost.
Logits Raw, unscaled score numbers from a neural network's final layer (e.g., [-1.8, +0.4, +4.2]) before conversion into probabilities. Cannot be compared directly against a 0.70 threshold until converted via Softmax.
Softmax Converts raw logits into positive probabilities between 0.00 and 1.00 that sum to exactly 1.00 (100%). Produces the tier distribution shown in Tab 5: e.g., {"flash_fast": 0.97, "flash_with_verifier": 0.03}.
Calibrated Softmax & ECE Aligns predicted probabilities with real-world empirical accuracy so a 0.80 probability truly happens ~80% of the time (low Expected Calibration Error). Makes numeric gateway sliders like fire_threshold = 0.70 reliable instead of clustering at 0 or 1.
Selective Prediction A model's ability to measure its own uncertainty (confidence) and defer borderline cases to a safer verification path. If Stage 1 confidence falls below your 0.75 gate, the gateway enforces Stage 2 Noul verification.
Bidirectional Cross-Encoder vs. Causal Decoder Causal decoders read strictly left-to-right; cross-encoders / System 1 evaluators cross-check every word in the candidate answer against every word in the RAG context simultaneously. Fast, accurate detection of factual contradictions and omitted constraints.
